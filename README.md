# Stock Market Predictor

A Machine Learning-based stock market prediction project that predicts whether Microsoft (MSFT) stock prices will rise or fall the next day using historical stock market data.

## Features
* Historical stock market analysis
* Time-series machine learning
* Random Forest classification
* Rolling average feature engineering
* Backtesting for realistic evaluation
* Data visualization using Seaborn

## Tool Used
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Dataset
The dataset contains historical Microsoft stock data including:
* Open price
* Close price
* High price
* Low price
* Volume

## Model
The project uses:
* Random Forest Classifier 
To predict:
* 1 → stock price increases tomorrow
* 0 → stock price decreases or remains same

Random Forest Algorithm handles nonlinear data  well.


## Backtesting
The project implements backtesting to simulate real-world stock prediction by training on past data and predicting future unseen data iteratively.


## Feature Engineering
* Custom features include:
* Rolling averages
* Trend indicators
* Price ratio analysis
